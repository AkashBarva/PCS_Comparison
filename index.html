How the tiers are computed — automated · indicative

Automated scoring  computed directly from the datasheet matrix — no manual input. Each vendor is scored on objective, measurable parameters: efficiency %, auxiliary kW, certificate count, overload %, temperature rating, DC-voltage window, and grid-support compliance.

Quality scored only on categories with real data (T1 ≥ 70, T2 52–69, T3 < 52). Completeness shows how much of the picture is present. Hover any Pros/Cons to see the exact figure behind each score.

⚠ Indicative only. These tiers reflect objective spec strength, not a full quality verdict — subjective factors (grid-forming maturity, reliability track record, service depth) need engineering review and are not auto-scored.
